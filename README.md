# Spam Email Detection Using a Custom Small Language Model (SLM)

## 1. Project Overview

This project develops a custom Small Language Model (SLM) using Transformer architecture to classify email messages into two categories: **Spam** and **Ham (Not Spam)**.

The custom model uses a Qwen-inspired architecture with Token Embeddings, Grouped Query Attention (GQA), RMS Normalization, Rotary Positional Embeddings (RoPE), and a SwiGLU-style Feed Forward Network.

The trained classification model is saved as a PyTorch checkpoint and hosted on Hugging Face.

The project also explores a hybrid demonstration that combines a spam classification model with Ollama for conversational explanations.

## 2. Project Objectives

- Develop a custom Transformer-based SLM.
- Detect spam and legitimate email messages.
- Implement text tokenization and preprocessing.
- Train a lightweight classification model.
- Evaluate classification performance.
- Host the trained model and dataset on Hugging Face.
- Maintain the complete project source code on GitHub.
- Develop an interactive spam detection demonstration using Ollama.
